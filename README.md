# 아케인 서지 (Arcane Surge) — 1지역 수직 슬라이스

판타지 3D 자동전투 디펜스 (three.js r160). 물결 소탕 리빌드 제안의 1차 구현 범위: 1지역(시작의 들판) 5구간 + 보스.

## 실행
```
cd game
python3 -m http.server 8902 --bind 127.0.0.1
# 브라우저에서 http://127.0.0.1:8902/
```
정적 파일만으로 동작. 빌드 없음.

## 테스트용 URL 파라미터 (디버그 전용)
- `?ts=N` — 균일 시간 배율 (예: ts=3은 3배속)
- `?stage=N` — N구간부터 시작 (강화 부대 지급)
- `?weak=1` — 아군 공격력 5% (패배 경로 테스트)
- `?bossonly=1` — 일반 적/보상 블록 스폰 억제 (보스 돌파 경로 단독 검증)
- `?gauge=N` — 초기 게이지 (합성 마법 테스트)
- `?fxslow=N` — 이펙트 수명 배율 (캡처 전용, 외형 불변)

## 검증 상태 (2026-11-25, 헤드리스 크롬 + 자동 플레이 하니스)
- 1~5구간 연속 완주(승리): 검증됨. 보스 전방 교전·처치 → 분열체 정리 → 승리.
- 생명 3→0 패배 경로: 검증됨.
- 보스 방어선 돌파 즉시패배(생명 유지 상태): 검증됨 (bossonly+weak 조합).
- 자동 공격은 전방·사거리 내 대상만 조준(보스 포함). 후방 자동 추적 사격 없음.
- 최대 밀집 + 합성 마법 시야: 검증됨. 대원 8 + 다수 적 + 보스 + 낙뢰 이펙트 동시 화면에서 아군/적 링, HUD, 라벨 판독 양호 (fxslow=8 캡처 보조 사용 — 이펙트 수명만 연장, 외형 동일).
- 헤드리스 환경 fps는 실기기 성능 근거로 사용 불가.
- 모든 수치(체력/공격력/속도/보상)는 초안. 실플레이 조정 필요.
