# 아케인 서지 (Arcane Surge)

판타지 3D 자동전투 디펜스 (three.js r160). 걸은 거리가 점수입니다. 40스테이지(8지역)를 끝까지 돌파하면 엔딩이 나오고, NG+ 다회차로 이어서 플레이할 수 있습니다.

## 진행 규칙 (2026-11-27)
- 전진 속도 2.3(기존 1.7 대비 +35%). 스테이지 경계에서 다음 파도가 미리 걸어오고(스폰 예지 24→34), 파도·보상 배치를 압축해 빈 이동 구간을 없앴습니다. 보스 구간은 격파 후에도 잔졸이 계속 도래합니다.
- 보스를 처치해도 처음으로 돌아가지 않고 계속 전진합니다. 5스테이지마다 보스(8종, 순환 없음), 보스 다음 스테이지부터 지역(맵 테마 8종)이 바뀌고 지역마다 등장 적 조합과 체력·속도 보정이 다릅니다. 하늘/안개는 보스 스테이지 후반부터 서서히 전환, 지형은 스테이지 단위 타일로 이어 붙입니다.
- 40스테이지의 최종 보스(종말의 마왕)를 쓰러뜨리면 클리어(엔딩). 이후 NG+ 다회차를 선택할 수 있습니다: 영구 해금된 병종은 유지되고, 다음 회차에 데려갈 시작 편성(병종 1종 + 소수 부하)을 고릅니다. 회차가 오를수록 적 체력 +45%/속도 +6%(상한)·블록 체력 +30%가 누적되고 시작 화력 +10%로 보정합니다.
- 난이도: 1스테이지 유지, 2스테이지부터 적 체력 1.5배 후 스테이지마다 약 1.3배(12 이후 1.15배), 파도당 적 수 증가(상한 8).
- 병종 개편(11-27): 전원 충분한 사거리(16 이상, 후드 로그는 유도라 사실상 무제한)를 갖고 공격 방식으로 차별화합니다. 직사 관통(나이트), 연발(로그), 산탄(레인저), 광역 파동+블록 3배(바바리안), 낙점 폭발(메이지), 관통 투창+감속(프로스트 랜서), 유도(후드 로그), 5연쇄(소서러), 지속 화염 고화력(파이로), 초장거리 광선(프리즘). 포격수는 제거. 사거리 상향분만큼 적 체력 +45%·속도 +10%(보스 체력도 +30%), 1스테이지 실효 난이도는 유지.
- 점수 = 걸어온 거리(m). 최고 기록은 localStorage에 저장되어 화면 좌측 상단에 항상 표시되고, 갱신 중에는 초록색으로 강조됩니다.
- 게임 오버: 거리/처치/스테이지/콤보/피해 구성/대마법/적 종류/부대 성장 대시보드.
- 대마법: 처치 20마리마다 자동 발동(토네이도 → 메테오 → 낙뢰 순). HUD에 게이지와 다음 마법이 표시되며 전방 끝까지 훑으며 피해를 줍니다.
- 보스 처치 시 생명 +1(최대 5).

## 실행
```
python3 -m http.server 8902 --bind 127.0.0.1
```
정적 파일만으로 동작. 빌드 없음.
