# 아케인 서지 (Arcane Surge)

판타지 3D 자동전투 디펜스 (three.js r160). 끝없이 이어지는 길을 걸은 거리가 점수입니다.

## 진행 규칙 (2026-11-27)
- 보스를 처치해도 처음으로 돌아가지 않고 계속 전진합니다. 5스테이지마다 보스(6종 순환), 보스 다음 스테이지부터 지역(맵 테마)이 바뀝니다. 하늘/안개는 보스 스테이지 후반부터 서서히 전환, 지형은 스테이지 단위 타일로 이어 붙입니다.
- 난이도: 1스테이지 유지, 2스테이지부터 적 체력 1.5배 후 스테이지마다 약 1.3배(12 이후 1.15배), 파도당 적 수 증가(상한 8).
- 점수 = 걸어온 거리(m). 최고 기록은 localStorage에 저장되어 화면 좌측 상단에 항상 표시되고, 갱신 중에는 초록색으로 강조됩니다.
- 게임 오버: 거리/처치/스테이지/콤보/피해 구성/대마법/적 종류/부대 성장 대시보드.
- 대마법: 처치 20마리마다 자동 발동(토네이도 → 메테오 → 낙뢰 순). HUD에 게이지와 다음 마법이 표시되며 전방 끝까지 훑으며 피해를 줍니다.
- 보스 처치 시 생명 +1(최대 5).

## 실행
```
python3 -m http.server 8902 --bind 127.0.0.1
```
정적 파일만으로 동작. 빌드 없음.

## 테스트용 URL 파라미터 (디버그 전용)
- `?ts=N` 시간 배율, `?stage=N` N스테이지부터 시작, `?weak=1`, `?bossonly=1`, `?fxslow=N`, `?nodraw=1`, `?nofx=1`
